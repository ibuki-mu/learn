- **身份**：大学生（在校）。

- **周期**：一年，每周 20–25 小时。
- **外部环境**：企业普遍短工期，强制要求 AI 提效开发。
- **核心诉求**：
  1. 短工期下用 AI 提效，但**不被 AI 架空**。
  2. 扩大知识边界，强化 AI 应用能力。
  3. 不落下自身开发学习。
  4. 需要可执行的路线、个人知识图谱和具体起步方法。

## 2. 当前真实水平（自测结论）

**总体判断**：不是零基础，是「**框架使用者**」，还不是「**工程师**」。
能跑通 CRUD，但不理解框架下的机制；一旦脱离框架或出故障，能力骤降。

**已具备**

- Java / Python 基础语法。
- Spring Boot + MyBatis 能写 CRUD。
- Maven 能建项目。
- 写过简单 JUnit 断言测试。

**8 题自测逐项结果（含评分口径，后续复测用同一套）**

| # | 题目 | 用户答案 | 判定与补正 |
|---|---|---|---|
| 1 | ArrayList / LinkedList | ArrayList 基于数组，LinkedList 是双向链表；认为 LinkedList「已不推荐使用」 | 基本正确。「不推荐」表述不准确：准确说法是**大多数场景不如 ArrayList 和 ArrayDeque** |
| 2 | HashMap | 数组+链表+红黑树，冲突挂链表，超阈值转红黑树 | 主体正确。**漏**：容量、负载因子、扩容机制、转红黑树条件（链表长度 ≥8 **且** 容量 ≥64）、退化阈值 6 |
| 3 | 异常 | checked 编译期检查，unchecked 运行时异常，通常是逻辑错误 | 正确。**缺**：Throwable 体系、Error、业务异常设计 |
| 4 | 接口 / 抽象类 | 接口多继承、抽象类单继承；接口一般不做方法实现，抽象类可以 | 基本正确。**缺**：Java 8+ 接口 default / static / private 方法 |
| 5 | Maven | 会用 pom.xml 创建项目 | 会用不深。**缺**：生命周期、依赖冲突、多模块、scope |
| 6 | 单元测试 | 写过简单断言 | **缺**：JUnit 5 高级特性、Mockito、集成测试、覆盖率 |
| 7 | Git | 一般用 AI | 🔴 **危险依赖**，必须手动掌握：分支、合并、冲突、rebase、PR 流程 |
| 8 | JDBC / MySQL | 没实操过 JDBC，都是直接用 Spring Boot + MyBatis | ❌ **最大知识缺口**，底层被框架掩盖 |

**两大结论**

- **最大断层**：Spring Boot + MyBatis 与 JDBC / MySQL 之间。
- **最大风险**：Git、调试、代码生成依赖 AI。

## 3. 已锁定的学习策略与原则（视为已确认决策）

1. **AI 定位**：导师、陪练、评审、模拟器、知识库 —— **不是答案机**。
2. **核心公式**：`AI 加速 = 高质量提问 × 主动验证 × 项目闭环 × 输出倒逼`。
3. **学习范式**：定目标 → AI 诊断缺口 → 最小项目 → 自己实现 → AI 评审 → 追问原理 → 输出复盘。
4. **三轨并行**：交付轨 60% / AI 应用轨 25% / 基本功轨 15%。
5. **每日节奏**：30 min 原理（源码/算法）+ 90 min 项目编码 + 30 min 复盘输出。
6. **每周节奏**：1 天**无 AI 手写核心模块**；1 次 AI 代码审查；1 次模拟面试或系统设计；1 篇技术复盘。
7. **AI 使用边界**
   - 放心交给 AI：样板代码、配置、CRUD、解释报错、生成测试、写文档、重构建议、知识地图。
   - **必须自己来**：核心业务逻辑、架构设计、表结构、安全、事务、一致性、性能取舍、故障根因、每一行 AI 代码的解释与验证。
8. **避坑清单**：不只复制代码；不信 AI 给的版本/API/性能数据；不上传敏感代码；不用 AI 替代思考；不跳过低层；不贪多。
9. **提问纪律**：先自己想 30 分钟再问 AI；AI 产出必须自己敲、跑、改、验证。

## 4. 一年学习路线

> **真相源已迁移**：路线图、项目串联、节奏、阶段关门流程、开局阻塞项一律以 [`ROADMAP.md`](ROADMAP.md) 为准，本节不再重复定义。

主线：Java + Spring Boot 后端开发。副线：AI 辅助开发工作流 + 计算机基础补强。每周投入 20–25 小时。

| 阶段 | 月份 | 主题 | 阶段产出 |
|---|---|---|---|
| 一 | 1–3 | Java 深化 + 计算机基础 | 纯 Java 命令行工具（含持久化 + 测试） |
| 二 | 4–7 | Web 后端 + 数据库 | 带登录/权限/CRUD 的 Web 系统，部署上云 |
| 三 | 8–10 | 工程化 + 分布式 + AI 应用 | 带 AI 能力的后端服务（RAG/Agent） |
| 四 | 11–12 | 冲刺与打磨 | 重构、系统设计文档、模拟面试、博客 |

**已确认的项目串联**（详见 [`ROADMAP.md`](ROADMAP.md) 与 [`projects/P-A-todo.md`](../projects/P-A-todo.md)）

| 编号 | 项目 | 技术栈 | 主补缺口 | 时间盒 |
|---|---|---|---|---|
| P-A | 待办管理器（命令行） | 纯 Java，禁用框架 | 集合、泛型、异常、IO、测试 | 3 周 |
| P-C | 图书借阅系统（命令行） | 纯 JDBC + MySQL，禁用 Spring | JDBC、事务、JOIN、索引 | 3.5 周 |
| P-B | 任务管理系统（Web） | Spring Boot + MyBatis + MySQL | 分层、DI、REST、Git、Mock 测试 | 7 周 |

**节奏**：每日 30 min 原理 + 90 min 编码 + 30 min 复盘；每周 1 天无 AI 手写核心、1 次独立子代理代码审查、1 次模拟面试或系统设计、1 篇复盘。

**阶段关门三件套**：自查清单逐条打勾 → 用户确认 → 原子 commit → 同步更新 [`KNOWLEDGE-GRAPH.md`](KNOWLEDGE-GRAPH.md)。
